Skibiddy Toilet is a locally generated robot vocal preset using macOS's Fred
voice. Normal keys rotate through “skibiddy”, “toilet”, “dop” and “yes yes”.
Space says “toilet”, Enter says “skibiddy toilet”, and Delete says “dop dop”.
Releases use a quiet synthetic pop. These are Keybed's generated vocal samples.

Recreate the bundled WAV files on a Mac with:

```sh
python3 Sounds/Skibiddy/generate.py
```

Playback uses preloaded audio and does not run speech synthesis while typing.
